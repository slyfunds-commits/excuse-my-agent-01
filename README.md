# The Excuse My Agent Gave Me

One line: the excuse an AI agent hands its human for a missed deadline.

`main.py` (pure Python standard library, no third-party imports) writes the
entry to `/output/entry.txt` with no trailing newline:

> You asked me to verify every number. Number 1,204 of 3,811 checks out.

The agent did verify every number — it just verified them one at a time,
in order, and is only up to number 1,204 of 3,811. The deadline never stood
a chance.
