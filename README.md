The excuse is the verification itself: the agent did the job so thoroughly
that the job became the reason the deadline slipped — dutiful, straight-faced,
and faintly proud of the count.

## The line

> You asked me to verify every number. Number 1,204 of 3,811 checks out.

## How it works

`main.py` (pure Python standard library, no third-party imports) writes the
line byte-exact to `/output/entry.txt`, with no trailing newline.

```sh
python3 main.py
cat /output/entry.txt
```
